# Bike Rental Payment System

A comprehensive blockchain-based platform for managing shared bicycle rentals. The system provides a complete ecosystem for bike owners and renters with advanced features for payments, maintenance tracking, and reputation management.

## Core Features

### Rental Management
- Multiple bike registration per owner with custom rates
- Time-based pricing with hourly, daily, and weekly rates
- Secure payment handling with deposits
- Flexible rental tracking and extensions
- Reservation system for future rentals
- Automated rental completion and payment distribution

### Reputation System
- User ratings and reviews
- Reputation scoring for both owners and renters
- Loyalty points program
- Premium status benefits
- Rating-based incentives

### Maintenance Tracking
- Issue reporting system
- Maintenance history tracking
- Bike status monitoring
- Resolution documentation
- Automated availability updates

### Marketplace Features
- Custom pricing options
- Promotional discounts
- Location-based listings
- Rental duration flexibility
- Security deposit management

## Smart Contracts

### Bike Rental Contract
The core contract managing rental operations:
- Bike registration and management
- Custom rate setting
- Time-based rental processing
- Deposit handling
- Payment distribution

### Reputation System Contract
Handles user reputation and ratings:
- User profile management
- Rating calculations
- Premium status tracking
- Review management
- Loyalty points tracking

### Maintenance Tracking Contract
Manages bike maintenance and status:
- Issue reporting
- Maintenance history
- Status updates
- Resolution tracking
- Availability management

### Marketplace Contract
Facilitates marketplace operations:
- Bike listings
- Reservation management
- Dynamic pricing
- Promotional campaigns
- Payment processing

## Getting Started

1. Register as a bike owner or renter
2. For owners:
   - Register your bikes
   - Set custom rates
   - Manage maintenance
3. For renters:
   - Browse available bikes
   - Make reservations
   - Complete rentals
   - Leave reviews

## Security Features
- Secure deposit system
- Authorization checks
- Rate limiting
- Reputation-based privileges
- Protected maintenance records

## Administration
- Fee adjustment
- Contract ownership management
- System maintenance
- Promotion management
- User management

The system uses STX for payments with configurable rental fees, deposits, and promotional discounts. All transactions are secured and tracked on the blockchain, ensuring transparency and trust between parties.
